# WeFlow Personal OS 产品路线图

> 目标：把本机微信增量数据变成一个证据可追溯、可搜索、可对话、可持续成长的个人行动与记忆系统。
>
> 原则：本地优先；微信 ID 是身份锚点；原文证据不可丢；不确定内容不冒充事实；所有自动合并可撤销；断电、离线和重启后可续跑；API Key 永不写入仓库。
>
> 产品硬规则：任何新增的后端记忆能力，必须在同一阶段提供可查看、可理解、可确认、可拒绝或可纠正的前端入口，不能只落库。

## 当前基线

- [x] 微信数据本地读取、时间戳增量续跑、启动补齐和每日调度
- [x] DeepSeek结构化抽取与 JSON 校验
- [x] 按会话分片，100 条核心消息与前后各 20 条重叠上下文
- [x] 联系人备注、微信昵称、群昵称、微信号与 wxid 身份 mapper
- [x] 信息来源开关及公众号硬过滤
- [x] 待办归属 `mine / uncertain / others` 与人工确认
- [x] 人物、组织、群、项目实体及有向关系
- [x] 关系原文证据、方向说明和人工确认
- [x] 增量身份消歧、正反决策持久化、可撤销合并
- [x] SQLite、全文搜索表和向量字段基础结构

## P0：可信个人记忆核心

### P0.1 个人事实 Claims

- [x] Prompt 同时抽取主语、谓词、值、有效期、置信度、来源性质
- [x] 区分本人陈述、他人陈述、模型推断和人工确认
- [x] 同一事实追加证据，不覆盖历史
- [x] 互相冲突的事实并存并进入确认状态
- [x] 支持事实人工纠正、有效期和纠正审计记录；人工纠正使用事务同步结构化值、状态、全文与向量失效，后续同 ID 重抽取只能追加原文证据，不得覆盖人工值、确认状态、来源性质或搜索文本
- 验收：可以回答“我在哪些公司工作过”，并列出时间、证据和冲突。

### P0.2 事件与时间线

- [x] 抽取会议、承诺、交付、旅行、付款、加入/离开组织等事件
- [x] 保存参与者、角色、时间范围、地点和证据
- [x] 相同证据且时间相同/缺失的事件自动聚合
- [x] 界面展示基础个人时间线；事件可在时间线或问答引用中纠正标题、类型、说明、上海时区起止时间与地点，前后版本写入审计并标记最近纠正时间，后续重抽取只追加证据；确定性来源删除仍可将人工纠正事件标为已取消，但不改写其人工内容
- 验收：可以回答“上个月发生了哪些重要事情”，每项可回到原消息。

### P0.3 证据与可信度

- [x] 事实、事件和关系保存 messageId 证据
- [x] 根据陈述来源区分直接证据和间接证据
- [x] 抽取肯定式标准谓词 + 正负极性；冲突事实双向挂接明确反证并在界面标注
- [x] 没有证据的事实与事件拒绝落库
- [x] 所有模型结构统一执行落库前证据门禁：待办、实体、关系、事实、事件和身份合并建议均引用 `sourceId:sessionId:messageId` 复合 evidenceKey；只接受当前分析窗口的 core 消息，裸消息 ID、伪造键、跨会话同号消息和 overlap context 引用均在任何图谱/数据库变更前剔除；新证据记录使用复合键避免跨会话主键碰撞
- [x] LLM 新增事实、事件和关系一律进入候选；只有人工操作与确定性规则可以确认
- [x] 实体摘要采用非破坏性证据候选：模型摘要必须绑定当前 core 原文，默认不写入可信实体摘要、不进入全文/向量检索、也不回送模型；界面同时展示建议摘要、现有摘要和逐条原文，人工确认后才生效，确认时若现有摘要已变化则候选自动失效，旧版无状态摘要明确标记“历史未验证”并从可信检索隔离
- [x] 建立首批 SQLite 回归测试，覆盖冲突事实、任务证据和中文检索回退
- [x] 建立任务归属匿名化合成黄金集和版本化规则评估器；后续持续追加真实错误的匿名变体
- 验收：任何界面结论都能展开查看原文、发送者和时间。

### P0.4 增量运行可靠性

- [x] ingestion run 持久化记录每批消息量、模型、Prompt 版本和结果
- [x] 每批持久化结构化证据门禁版本及六类输出的接受/拒绝数量，完整诊断页展示无效引用被拦截的数量
- [x] 分批写入与 checkpoint，单批失败不丢失前批结果
- [x] JSON 自动修复与失败批次重试
- [x] 失败批次本地保留并在下次按 checkpoint 重试；支持当前批次后安全暂停、继续和实时批次进度/错误界面
- [x] 个人记忆数据库与状态联合备份、受控恢复、一致性检查和最近 10 份保留
- [x] 跨设备备份导入与迁移向导：数据库、图谱/任务状态和增量游标打包，SHA-256 校验、导入预览与恢复前安全快照
- 验收：任意时刻强制退出，再启动能从最后成功批次继续。

## P1：混合检索与证据问答

### P1.1 全文与图搜索

- [x] 统一全文搜索实体、别名、关系、事实、事件和任务
- [x] 图查询：任意实体间最短关系路径，保留每一步方向和证据
- [x] 共同联系人/共同实体查询、全局时间过滤和图谱关系类型/确认状态过滤；共同关系保留方向、状态、置信度和证据
- [x] 中文分词、全拼/首字母拼音、模糊别名和微信 ID 查询，并在统一搜索中解释命中方式
- 验收：搜索任意人物时同时返回身份、关系、事件、事实和相关任务。

### P1.2 本地向量搜索

- [x] 选择 MIT 许可的 BGE-small-zh-v1.5 中文 embedding 模型（24M 参数、512 维）
- [x] Transformers.js + ONNX Runtime 本地推理，批量生成并增量补齐向量
- [x] 内容 SHA-256 去重、模型版本和维度校验，内容变化自动使旧向量失效
- [x] SQLite 保存向量并以归一化余弦相似度本地检索
- [x] 实体与统一记忆向量达到 2,000 条后自动切换到本地持久化多探针 LSH ANN 索引；6 张确定性哈希表与原始向量同存于 SQLCipher，内容/模型/维度变化由触发器精确失效，索引版本或覆盖率不完整、规模不足、候选量不足时自动回退精确余弦扫描；索引可事务重建且重启后复用，统一检索结果标记实际搜索模式，完整诊断展示精确/ANN、覆盖率、版本、阈值和最近构建时间；300 条聚类回归集验证 recall@10 ≥ 0.8，M4 本机 2,100 条 × 512 维基准为构建 229ms、精确查询 74.89ms、ANN 查询 42.42ms、recall@20=1.0
- 验收：用语义而非原词也能找回相关聊天记忆，并显示证据。

### P1.3 RAG 对话

- [x] 本地记忆问答入口和会话历史
- [x] 全文与向量混合召回、分数融合并向界面解释命中来源
- [x] 确定性查询规划器自动组合多表达召回、实体、图路径、上海时区时间约束、记忆与关系类型，并在界面解释规划
- [x] 回答必须引用本地证据，不足时明确说不知道
- [x] 统一可信状态与问答证据资格：已拒绝事实/关系/事件保留加密审计但从普通搜索和模型上下文排除；待确认候选与已取消历史仍可在本机审阅，但明确标记且不能支持事实结论；只有已确认或非推断型原始资料在确有原文证据时才能成为引用，模型即使返回候选、取消或伪造引用也会被本地白名单剔除，最终无合格引用时强制改为“证据不足”；搜索卡片和回答引用同步显示可信状态
- [x] 搜索与问答统一支持“仅查某人/某群/某时间段/某类记忆”，范围约束在全文 FTS、精确向量和 ANN 候选召回之前由数据库统一执行，覆盖实体 ID/别名、结构化主客体与参与者、原文会话、上海时区证据/有效期/事件/截止时间、文档及关系类型；召回后再次执行同一语义校验形成双层防线，范围外内容既不参与 Top-K 排序也不发送给模型，界面与查询规划展示召回前候选数量
- [x] 支持从回答生成带引用证据的待办、进入事实纠错、确认或拒绝事实/事件/关系
- 验收：回答“最近谁在等我回复”时，可给出可靠列表和原文引用。

## P2：行动助理

### P2.1 完整任务系统

- [x] 待办负责人、协作者、截止时间、来源、项目和依赖均可抽取、持久化、检索和人工编辑
- [x] 任务按原消息证据优先去重；状态、延期、取消、完成及编辑变化写入带证据的审计历史
- [x] 人工编辑标题、说明、负责人、截止时间、优先级和状态
- [x] 按状态和优先级过滤，并批量完成当前筛选
- [x] 上海时区任务月历，复用任务筛选并展示每日任务、逾期事项和未排期待办
- [x] 对“我交给别人”的事项建立 delegated 类型，并区分 waiting 等待他人状态
- 验收：自己的任务、委派任务和等待他人回复不会混淆。

### P2.2 主动提醒与每日简报

- [x] 逾期、48 小时临期、等待过久和依赖阻塞提醒，界面解释触发原因并每日去重通知
- [x] 最新增量/本周简报聚合，支持跨午夜静默时段；静默期间继续补齐但不发送系统通知
- [x] 简报摘要与重点信息逐条绑定原文：Prompt/schema 使用跨来源复合 evidenceKey，模型摘要必须提供 summaryEvidenceKeys、每条 highlight 必须提供 sourceEvidenceKeys；本地只接受当前分析批次中 `analysisScope=core` 的真实键，伪造键、overlap 上下文和旧版无引用字符串全部拒绝进入新简报；每日摘要和重点可展开查看会话、发送人和原文，历史无引用摘要/重点继续保留但明确标记“历史未验证”，每周聚合继承验证状态
- [x] 电脑离线期间按 checkpoint 补算；通知使用持久化待发队列和稳定去重键，静默结束或重启后重放，成功后才记账
- [x] 提醒反馈用于修正个人偏好：支持有用反馈、单条推迟 24 小时、关闭/恢复提醒类型，持久化后同时约束界面和系统通知
- 验收：提醒可解释“为什么现在提醒”，并能一键处理。

### P2.3 项目与目标

- [x] 自动识别项目实体；按任务状态推断阶段与进度，按逾期/等待/依赖规则识别风险，并从交付/会议/组织变化/决策事件聚合里程碑和决策
- [x] 将聊天任务按结构化 project 字段及项目实体别名归入项目，并兼容尚无图实体的派生项目
- [x] 项目驾驶舱聚合参与者、任务进度、逾期/等待/依赖风险、里程碑、决策和去重原文证据
- [x] 项目派生结论传播可信状态：只有已确认关系进入参与者、已确认事件进入里程碑/决策、已确认事实进入项目事实与确定性证据统计；待确认关系/事件/事实集中进入独立候选区并显示数量和“不参与确定性统计”说明，取消与拒绝事件不进入项目当前状态
- 验收：打开项目即可看到参与人、进展、任务、风险和关键证据。

## P3：人物与关系智能

- [x] 图谱实体详情面板：身份、别名、账号、关系、事实和相关事件
- [x] 独立人物档案层：完整身份、事实证据、关系与变化历史、事件时间线、关联待办及统一检索联动
- [x] 实体详情展示可解释关系强度、最近互动证据、去重证据数、关联待办与待确认承诺
- [x] 人物关系强度只用已确认关系计分并明确显示“已确认关系”；候选关系保留真实互动证据与独立待确认数量，但不再冒充有效关系或抬高关系分
- [x] 多账号实体候选的规则召回、档案向量召回和共享邻居图召回，统一进入带来源信号的人工确认队列
- [x] LLM 实体禁止凭“同名＋高置信度”静默复用人物；人物只有在账号 ID 确实来自该实体 core 原文发送者身份，且通讯录备注/昵称/群昵称/微信号与实体名称相符时才允许确定性复用，模型伪造或错配账号直接丢弃；无稳定锚点的同名人物创建独立实体并进入可解释人工合并候选，非人物实体保留同类型唯一精确名的受控复用
- [x] 身份别名采用双轨可信策略：只有实体规范名与同一条 core 原文发送者身份匹配，且别名也确实出现在该发送者通讯录备注、昵称、群昵称或微信号中时才确定性写入；其余模型别名逐个进入带复合消息键和原文摘录的人工候选，确认前不参与消歧、合并、全文或向量检索，跨发送者名称不能冒充该实体别名，实体合并时自动关闭失效候选
- [x] 每日增量消歧；实体达到 500 后开启每 7 天一次的名称索引全图巡检
- [x] “确定不是同一人”负样本和版本冷却策略；身份版本未变化时不再重复提示
- [x] 关系变化历史：首次发现、证据/置信度更新和人工状态变化均保留快照，并在实体详情展示
- 验收：同名不误合并、多号不重复展示、每次合并可解释可撤销。

## P4：多模态本地理解

- [x] 语音消息复用 SenseVoice 本地转写与持久化缓存进入证据索引；按设置启用、单次预算 12 条且模型缺失时不自动联网下载
- [x] 图片 OCR、截图结构化和文档附件解析（已完成图片本地解密、Tesseract 中英 OCR、SHA-256 缓存、单次 8 张预算和证据索引；OCR 后会本地识别聊天/表格/表单/文档并提取字段、日期、金额和链接；普通图片使用随应用签名的 macOS Apple Vision helper 在设备端提取场景/物体候选，每轮最多 4 张，SHA-256 缓存且绝不上传原图；候选标签保留置信度并在资源界面明确标注“未经人工确认”，Prompt 禁止其单独支持任务、事实、事件或关系；已支持常见文本、DOCX/PPTX/XLSX 及含文本层 PDF；XLSX 已保留工作表、行列、表头、日期、公式结果和超链接，结构元数据可在资源界面查看并进入全文/向量检索，且对精简/第三方 OOXML 导出提供兼容兜底；DOCX 已保留标题层级、段落、列表、普通表格、字段表及页眉页脚；PPTX 已保留真实页序、标题、文本块和表格，无标题占位符时进行带来源与可信度的版面推断；DOCX/PPTX/XLSX 内嵌 OOXML 图表已能本地恢复标题、柱/线/饼/环/面积/散点/雷达/气泡类型、系列名、分类与缓存值，最多 40 张图表、每图 12 个系列和 100 个点，图表语义进入正文检索并可在资源界面审阅；含文本层 PDF 使用 Poppler bbox 坐标保存逐页文本区块，可靠检测左右栏与跨栏分隔块并按左栏→右栏建立稳定阅读顺序，单栏自动回退从上到下，版面类型、区块数和可信度可在资源界面审阅；旧 Office/PDF 资源每轮限速补做 1 个，断电后继续，失败按 1/2/4/7 天退避，成功后重建全文索引并使旧向量失效，界面显示完成/待处理/退避数量；扫描版 PDF 使用 Poppler 120 DPI 渲染并以 Tesseract 中英 OCR，每轮续扫一个文档的 3 页，持久化 nextPage 游标，断电重启后继续，追加正文会同步更新全文索引并使旧向量失效；逐页 20 秒预算且始终清理临时文件）
- [x] 链接标题、网页快照与附件内容索引（统一资源记忆保留原消息证据并进入全文/向量索引；附件正文增量补入同一资源；网页快照为显式开关，固定公开 80/443 端口并在 DNS 解析后锁定公网 IP，拒绝内网/回环/链路本地/元数据地址；兼容 macOS 代理 Fake-IP，但必须先经固定公网 DoH 二次验证真实解析结果；限制为单轮 4 个、512KB、8 秒和 3 次重定向）
- [x] 表情、引用、转发记录和小程序卡片语义恢复：保留媒介类型、引用对象/原作者/原文，并约束模型不得把引用承诺归给回复者
- [x] 敏感内容本地脱敏策略：本地证据仅隐藏凭证类秘密；发送 DeepSeek 前提供“仅凭证/标准/严格”三档策略，以稳定占位符隐藏 API Key、密码、令牌、邮箱、手机号、身份证、有效银行卡、IP 和链接凭证；增量抽取与 RAG 共用同一脱敏层，批次诊断和问答界面只显示分类命中计数、不保存敏感原值
- 验收：任务和事实可以来自语音、截图与附件，并明确标注识别来源。

## P5：质量、隐私与产品化
