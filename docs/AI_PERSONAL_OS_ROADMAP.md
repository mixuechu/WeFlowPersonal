# WeFlow Personal OS 产品路线图

> 目标：把本机微信增量数据变成一个证据可追溯、可搜索、可对话、可持续成长的个人行动与记忆系统。
>
> 原则：本地优先；微信 ID 是身份锚点；原文证据不可丢；不确定内容不冒充事实；所有自动合并可撤销；断电、离线和重启后可续跑；API Key 永不写入仓库。

## 当前基线

- [x] 微信数据本地读取、时间戳增量续跑、启动补齐和每日调度
- [x] DeepSeek结构化抽取与 JSON 校验
- [x] 按会话分片，100 条核心消息与前后各 20 条重叠上下文
- [x] 联系人备注、微信昵称、群昵称、微信号与 wxid 身份 mapper
- [x] 信息来源开关及公众号硬过滤
- [x] 待办归属 `mine / uncertain / others` 与人工确认
- [x] 人物、组织、群、项目实体及有向关系
- [x] 关系原文证据、方向说明和人工确认
- [x] 增量身份消歧、正反决策持久化、可撤销合并
- [x] SQLite、全文搜索表和向量字段基础结构

## P0：可信个人记忆核心

### P0.1 个人事实 Claims

- [x] Prompt 同时抽取主语、谓词、值、有效期、置信度、来源性质
- [ ] 区分本人陈述、他人陈述、模型推断和人工确认
- [x] 同一事实追加证据，不覆盖历史
- [ ] 互相冲突的事实并存并进入确认队列
- [ ] 支持事实失效、纠正和时间版本
- 验收：可以回答“我在哪些公司工作过”，并列出时间、证据和冲突。

### P0.2 事件与时间线

- [ ] 抽取会议、承诺、交付、旅行、付款、加入/离开组织等事件
- [ ] 保存参与者、角色、时间范围、地点和证据
- [ ] 相同事件跨消息聚合，不重复建档
- [ ] 界面展示可筛选个人时间线
- 验收：可以回答“上个月发生了哪些重要事情”，每项可回到原消息。

### P0.3 证据与可信度

- [ ] 所有任务、事实、事件、关系必须带 messageId
- [ ] 区分直接证据、间接证据和反证
- [ ] 没有证据的模型输出拒绝落库
- [ ] 自动确认只允许确定性规则，LLM高分仍可人工审核
- [ ] 建立错误反馈样本库与回归测试集
- 验收：任何界面结论都能展开查看原文、发送者和时间。

### P0.4 增量运行可靠性

- [ ] ingestion run 持久化记录每批输入、模型、Prompt 版本和结果
- [x] 分批写入与 checkpoint，单批失败不丢失前批结果
- [ ] JSON 修复、重试、限流和指数退避
- [ ] 离线队列、取消、继续及运行进度界面
- [ ] 数据库备份、恢复、导入和一致性检查
- 验收：任意时刻强制退出，再启动能从最后成功批次继续。

## P1：混合检索与证据问答

### P1.1 全文与图搜索

- [ ] 统一搜索实体、别名、关系、事实、事件、任务和证据
- [ ] 图查询：共同联系人、路径、时间过滤和关系类型过滤
- [ ] 中文分词、拼音、模糊别名和微信 ID 查询
- 验收：搜索任意人物时同时返回身份、关系、事件、事实和相关任务。

### P1.2 本地向量搜索

- [ ] 选择适合 Apple Silicon 的本地中文 embedding 模型
- [ ] CoreML/ONNX 或 Metal 后端，批量生成与增量更新向量
- [ ] 内容哈希去重、模型版本和维度迁移
- [ ] SQLite 向量索引或本地 ANN 索引
- 验收：用语义而非原词也能找回相关聊天记忆，并显示证据。

### P1.3 RAG 对话

- [ ] 对话入口和会话历史
- [ ] 查询规划：全文、向量、图搜索自动组合
- [ ] 回答必须引用本地证据，不足时明确说不知道
- [ ] 支持“仅查某人/某群/某时间段”
- [ ] 支持从回答生成待办、纠正事实和确认关系
- 验收：回答“最近谁在等我回复”时，可给出可靠列表和原文引用。

## P2：行动助理

### P2.1 完整任务系统

- [ ] 待办负责人、协作者、截止时间、来源、项目和依赖
- [ ] 任务去重、状态变化、延期、取消和完成证据
- [ ] 人工编辑、批量操作、过滤和日历视图
- [ ] 对“我交给别人”的事项建立 delegated 类型及等待回复状态
- 验收：自己的任务、委派任务和等待他人回复不会混淆。

### P2.2 主动提醒与每日简报

- [ ] 逾期、临期、无人回复和承诺未兑现提醒
- [ ] 每日/每周简报，支持静默时段
- [ ] 电脑离线期间按 checkpoint 补算，不重复推送
- [ ] 提醒反馈用于修正个人偏好
- 验收：提醒可解释“为什么现在提醒”，并能一键处理。

### P2.3 项目与目标

- [ ] 自动识别项目、阶段、里程碑、风险和决策
- [ ] 将聊天任务归入项目
- [ ] 项目记忆、周报和决策日志
- 验收：打开项目即可看到参与人、进展、任务、风险和关键证据。

## P3：人物与关系智能

- [ ] 人物详情页：身份、别名、账号、关系、时间线、事实和互动摘要
- [ ] 关系强度、最近联系、承诺和未回复事项
- [ ] 多账号实体候选的规则召回、向量召回和图召回
- [ ] 每日增量消歧；实体达到 500 后开启低频全图巡检
- [ ] “确定不是同一人”负样本和候选冷却策略
- [ ] 关系变化历史，不把过去状态覆盖成当前状态
- 验收：同名不误合并、多号不重复展示、每次合并可解释可撤销。

## P4：多模态本地理解

- [ ] 语音消息本地转写并进入证据索引
- [ ] 图片 OCR、截图结构化和文档附件解析
- [ ] 链接标题、网页快照与附件内容索引
- [ ] 表情、引用、转发记录和小程序卡片语义恢复
- [ ] 敏感内容本地脱敏策略
- 验收：任务和事实可以来自语音、截图与附件，并明确标注识别来源。

## P5：质量、隐私与产品化

- [ ] Prompt、模型和抽取 schema 版本管理
- [ ] 黄金样本、自动回归、精确率/召回率和成本统计
- [ ] 数据保留策略、字段级删除、联系人彻底遗忘
- [ ] 本地数据库加密、日志脱敏和权限审计
- [ ] 诊断页：运行状态、失败批次、Token 与耗时
- [ ] 新用户引导、备份迁移、版本升级和崩溃恢复
- [ ] 模块化数据源接口，为邮件、日历、文档等预留连接器
- 验收：可以作为独立产品长期运行，并能解释数据从何而来、如何删除。
